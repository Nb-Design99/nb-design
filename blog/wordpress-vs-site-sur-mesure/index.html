WordPress ou site sur mesure : le vrai comparatif

Publié le 8 juillet 2026 · Lecture 7 min

WordPress représente 43 % des sites web dans le monde. C'est massif, et c'est un vrai atout pour beaucoup de projets. Mais est-ce que c'est vraiment le bon choix pour un restaurant, un artisan ou une PME suisse en 2026 ? On démonte les mythes et on tranche.

Qu'est-ce qu'un site WordPress exactement ?

WordPress est un CMS (Content Management System) open source. Concrètement, c'est un logiciel installé sur votre hébergeur qui vous permet de gérer votre site depuis une interface d'administration. Vous choisissez un thème (l'apparence), vous installez des plugins (les fonctionnalités), et vous éditez le contenu depuis un tableau de bord.

Qu'est-ce qu'un site sur mesure ?

Un site codé sur mesure est écrit à la main en HTML, CSS et JavaScript modernes. Pas de CMS, pas de thème préfabriqué, pas de plugin tiers. Chaque ligne de code est écrite spécifiquement pour votre projet. C'est ce qu'on fait chez NB-Design.

2. Sécurité

WordPress est la cible n°1 des cyberattaques sur le web, précisément parce qu'il équipe 43 % des sites. Chaque plugin installé est un vecteur potentiel de faille. En 2024, on estime que 90 % des sites WordPress piratés l'ont été à cause d'un plugin non mis à jour.

Un site sur mesure sans CMS ni base de données ne présente aucune surface d'attaque. Il n'y a rien à pirater : pas d'admin, pas de plugin, pas de faille.

4. SEO

WordPress a un bon SEO si vous installez et configurez correctement Yoast ou Rank Math. Cela demande une expertise. Sans configuration, le SEO est médiocre.

Un site sur mesure a le SEO qu'on lui donne. Chez NB-Design, on intègre systématiquement :

  • Balises meta parfaites (title, description, canonical)
  • Schema.org Restaurant en JSON-LD
  • Sitemap.xml propre et robots.txt
  • Structure sémantique H1/H2/H3
  • Open Graph pour les partages sociaux
  • Optimisation des images (alt, formats modernes)

5. Personnalisation visuelle

Avec WordPress, vous êtes limité par votre thème. Sortir des cases prédéfinies demande soit de payer un développeur pour customiser (cher), soit d'ajouter des plugins (lents et complexes).

Avec le sur mesure, tout est possible. Chaque animation, chaque interaction, chaque détail visuel est conçu spécifiquement pour votre marque.

6. Dépendance

WordPress dépend de l'écosystème WordPress. Si un plugin critique arrête d'être maintenu, votre site peut cesser de fonctionner. C'est arrivé plusieurs fois à des clients de collègues.

Un site sur mesure est autonome. Il utilise les technologies natives du web (HTML, CSS, JS) qui n'iront jamais nulle part.

Quand WordPress reste pertinent

WordPress a de vraies forces :

  • Blog très actif avec plusieurs contributeurs et 3+ articles par semaine
  • E-commerce complexe avec 500+ produits et gestion de stock (WooCommerce)
  • Sites multi-utilisateurs (forum, communauté, marketplace)
  • Contrainte budgétaire forte avec besoin de mettre à jour le contenu très souvent en interne

Quand le sur mesure écrase WordPress

  • Site vitrine restaurant, PME ou artisan
  • Site où la vitesse mobile est cruciale (fréquentation locale, 4G)
  • Site avec identité visuelle forte et animations custom
  • Client qui ne veut jamais toucher à la technique
  • Besoin de tranquillité totale (pas de piratage, pas de mise à jour)

Notre verdict honnête

Pour 95 % des restaurants et PME suisses, un site codé sur mesure est le meilleur choix en 2026. Vous obtenez un site 10 fois plus rapide, aucune faille de sécurité, un design unique, et une tranquillité totale.

WordPress reste pertinent pour les 5 % restants : gros blogs, e-commerces complexes, sites multi-utilisateurs. Si vous êtes dans ces cas, prenez WordPress. Sinon, fuyez.
